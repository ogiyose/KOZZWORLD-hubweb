# Kozzworld portfolio prototype

Open `index.html` in a modern browser. Plain HTML, CSS and JavaScript; no installation or build required. Not published.

Story, World, Goods and Player use hash navigation. Project cards open details; story format filters work. Save projects to the local Player preview and edit its display name. Change Wave on the homepage switches two sample themes. These preferences use localStorage when available. Reset Preview clears the Player name and saved projects.

All project descriptions and goods are illustrative. No authentication, checkout, CMS or backend is connected. Wave switching demonstrates local interaction, not a production publishing control.

Graphics are made with CSS and typography. Google Fonts enhance the typography when online; system fonts provide offline fallbacks. Replace sample content in app.js and adjust layout in style.css. POPEYE Web is the editorial layout reference, not a source of copied assets.
